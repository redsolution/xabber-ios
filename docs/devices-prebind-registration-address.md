The Devices registration IQ must target the authenticated account's own bare JID. XEP-DEVICES registration examples and web12659fe2 (`packages/core/src/strophe-xabber.js::_getXToken`) use this explicit recipient. The server pre-bind `mod_devices` hook passes the original IQ into `xmpp:make_iq_result`; it does not run normal bound-stanza routing normalization first. Supplying the correct request recipient permits an own-bare response while retaining strict response validation.
