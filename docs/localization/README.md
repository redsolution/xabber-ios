# Localization artifacts

`active-keys.json` is generated by `tools/localization_manifest.py` and is the
canonical inventory of app/push localization usage. Manifest-owned translation
coverage includes both `activeKeys` and `domainReservedKeys`.

`active-translations.csv` is a deterministic UTF-8 review/export table with
columns `id,en,ru,fr,es,ar,zh-Hans`. Plain strings are stored directly. Native
plural and String Catalog substitution values are stored as compact JSON in the
locale cell so every CLDR form remains lossless in one row.

Regenerate it explicitly after an approved catalog or manifest change:

```sh
python3 -B tools/localization_completion.py csv \
  --catalog xabber/translations/Localizable.xcstrings \
  --manifest docs/localization/active-keys.json \
  --output docs/localization/active-translations.csv
```

Validate the six-language active catalog and the checked-in CSV with:

```sh
python3 -B tools/localization_catalog.py \
  xabber/translations/Localizable.xcstrings \
  --manifest docs/localization/active-keys.json
python3 -B tools/localization_completion.py check-csv \
  --catalog xabber/translations/Localizable.xcstrings \
  --manifest docs/localization/active-keys.json \
  --output docs/localization/active-translations.csv
```

Non-English additions generated during completion are structured drafts. They
preserve runtime, placeholder and plural contracts, but Arabic/RTL, Simplified
Chinese, legal, privacy, security and destructive-action copy still require
native/product editorial review before final language-quality sign-off.
